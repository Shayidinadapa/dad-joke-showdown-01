Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on [make.fun](https://make.fun).

## What it does

`main.ts` writes one original dad joke — at most 200 characters, a single line — to `/output/entry.txt`. The program is fully deterministic: every run writes the exact same joke.

## Run it

```sh
node main.ts
```

Requires Node 22 or later. The joke lands in `/output/entry.txt`.
